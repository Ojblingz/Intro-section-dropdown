# Intro Section with Dropdown Navigation

This is my solution to the Intro Section with Dropdown Navigation challenge from Frontend Mentor.

![Project preview](./preview.jpg)

## Overview

I built a responsive landing page with interactive dropdown menus and a mobile navigation menu. The goal was to recreate the design as closely as possible while making sure the page works on different screen sizes.

### Features

- Responsive desktop and mobile layouts
- Interactive Features and Company dropdown menus
- Mobile navigation menu with open and close controls
- Mobile dropdown menus

### Built With

- HTML5
- CSS3
- JavaScript
- Flexbox
- Media queries

### What I Learned

This project helped me practise responsive web design, positioning dropdown menus, using JavaScript to toggle classes, and creating a mobile navigation menu. I also learned more about debugging layout issues and checking my work across screen sizes.
